# Code of Conduct

WhatsDesk Multi should be a practical and respectful project for people building better desktop workflows.

Please be:

- Clear
- Kind
- Patient
- Specific when reporting issues
- Careful with private WhatsApp screenshots or customer data

Unacceptable behavior includes harassment, abuse, spam, doxxing, or sharing private chat data without permission.

Maintainers may remove issues, pull requests, comments, or contributors that harm the project or its users.
