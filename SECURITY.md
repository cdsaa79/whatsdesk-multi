# Security Policy

## Reporting Security Issues

Please do not open public issues for security-sensitive reports.

For now, report privately to the repository maintainer.

## Scope

Security-sensitive areas include:

- Session isolation between WhatsApp instances
- Local CRM data storage
- Link routing
- Custom protocol handling
- Electron preload and IPC boundaries

## Privacy Expectations

Do not include real WhatsApp chats, phone numbers, customer records, QR codes, cookies, or session data in public reports.
